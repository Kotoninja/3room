# 01.5: Базовый инструментарий работы с 2D/3D-моделью помещения

**Status:** resolved

**Blocked by:** 01 — Автоматическое преобразование архитектурного чертежа в редактируемую 3D-модель

Владелец выбирает стены и вершины, правит граф в 2D, измеряет расстояния и осматривает ту же модель в 3D. История хранит только изменения геометрии. Сложные соединения и пересечения относятся к задаче 02.

## Критерии приёмки

- [x] Панель инструментов работает.
- [x] Можно выбрать и выделить стену.
- [x] Можно переместить стену и вершину.
- [x] Можно добавить и удалить стену.
- [x] Можно изменить параметры стены.
- [x] Работают привязки к сетке и вершинам.
- [x] Работает инструмент измерения.
- [x] Работают Undo и Redo.
- [x] Доступны управление камерой и переключение видов.
- [x] Выделение синхронизируется между 2D и 3D.
- [x] Панель свойств отображает и изменяет параметры объектов.
- [x] Изменения сразу отражаются в 2D и 3D.
- [x] Автоматическое распознавание чертежей продолжает работать.
- [x] TypeScript и сборка проходят.
- [x] Соответствующие тесты Vitest и Playwright проходят.

## Comments

Проверено 15 из 15 критериев. TypeScript, сборка и линтер прошли, Vitest — 10 из 10, Playwright — 10 из 10. Сквозная проверка покрывает выбор, перетаскивание стены и вершины, обе привязки, размеры, измерение, панорамирование, историю и выбор стены в 3D с возвратом в 2D. Регрессия распознавания проверена с реальными весами ONNX на трёх архитектурных планах и JPEG-версии одного из них.

Перемещение общей вершины обновляет связанные стены. История хранит до 100 изменений геометрии и ведётся в рамках загруженного проекта. Поля применяются по Enter или при уходе фокуса. Управление геометрией мышью выполняется в 2D. Продвинутые соединения остаются в задаче 02.
