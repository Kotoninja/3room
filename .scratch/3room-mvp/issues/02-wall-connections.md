# 02: Соединение и перемещение стен

**Status:** ready-for-agent

**What to build:** Владелец строит и перемещает стены в 2D, получая согласованные стыки в обоих видах.

**Blocked by:** 01.5 — Базовый инструментарий работы с 2D/3D-моделью помещения

## Критерии приёмки

- [ ] У каждой стены уникальный ID и ссылки на начальную и конечную вершины. Привязка повторно использует существующую вершину.
- [ ] Т-стык делит существующую стену, крестообразное пересечение делит обе. Частичное наложение отклоняется с подсказкой и сохраняет прежний граф.
- [ ] Зафиксированы отдельные численные допуски привязки в экранных пикселях и проверки геометрии в метрах. Vitest проверяет стыки, наложения и границы допусков через публичные операции.
- [ ] Сохранены согласованные ADR и единая модель данных для 2D и 3D. Выполнены проверка TypeScript, сборка и применимые проверки Vitest и Playwright для доступных сценариев.
