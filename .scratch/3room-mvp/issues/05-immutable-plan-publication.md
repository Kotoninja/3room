# 05: Публикация неизменяемого плана по ссылке

**Status:** ready-for-agent

**What to build:** Владелец публикует снимок с тестовым кодом и передаёт арендатору ссылку для просмотра.

**Blocked by:** 03 — Смежные помещения и их площади

## Критерии приёмки

- [ ] Выбрано, подключено и документировано реальное серверное хранилище снимков и контракт публикации. Ссылка проверена в другом браузере и на другом устройстве, независимо от localStorage владельца.
- [ ] Сервер проверяет код и откалиброванную метрическую геометрию. Кандидаты распознавания и диагностические отметки остаются локальными. Неверный код отклоняется. Публикации используют один вымышленный профиль без сбора контактных данных.
- [ ] Снимок имеет непредсказуемый уникальный ID и версию формата. По ссылке без входа доступны 2D и 3D в режиме чтения. Правки черновика не меняют выданный снимок.
- [ ] Публикация передаёт только разрешённые поля геометрии. Playwright проверяет отказ при неверном коде, открытие ссылки в отдельном контексте, неизменность снимка и отсутствие подложки, мебели, заметок, служебных данных и кода доступа в ответе.
- [ ] Сохранены согласованные ADR и единая модель данных для 2D и 3D. Выполнены проверка TypeScript, сборка и применимые проверки Vitest и Playwright для доступных сценариев.
