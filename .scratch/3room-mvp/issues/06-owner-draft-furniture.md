# 06: Мебель в черновике владельца

**Status:** ready-for-agent

**What to build:** Владелец расставляет мебель в черновике и осматривает результат в 3D.

**Blocked by:** 04 — Восстановление и перенос проекта владельца

## Критерии приёмки

- [ ] В 2D можно добавить экземпляр мебели с уникальным ID и переместить его, в том числе между помещениями. 3D сразу показывает новое положение.
- [ ] Автосохранение и перенос JSON восстанавливают мебель с теми же ID и положением.
- [ ] Мебель относится к локальному проекту. Playwright проверяет размещение, перемещение и восстановление.
- [ ] Сохранены согласованные ADR и единая модель данных для 2D и 3D. Выполнены проверка TypeScript, сборка и применимые проверки Vitest и Playwright для доступных сценариев.
