# 09: Восстановление и перенос расстановки

**Status:** ready-for-agent

**What to build:** Арендатор продолжает расстановку после перезагрузки или переносит её в другой браузер.

**Blocked by:** 08 — Пробная расстановка оборудования арендатора

## Критерии приёмки

- [ ] Локальная расстановка восстанавливается по ID снимка. Расстановки для разных снимков изолированы.
- [ ] Экспорт и импорт сохраняют ID снимка, габариты, положения и повороты оборудования. Повреждённый файл, неподдерживаемый формат или другой ID снимка отклоняются с сообщением и сохраняют текущую расстановку.
- [ ] Playwright проверяет повторное открытие ссылки и перенос в чистый браузерный контекст. Полный сквозной прогон от локального распознавания чертежа до переноса расстановки выполняется, когда также доступна задача 04.
- [ ] Сохранены согласованные ADR и единая модель данных для 2D и 3D. Выполнены проверка TypeScript, сборка и применимые проверки Vitest и Playwright для доступных сценариев.
