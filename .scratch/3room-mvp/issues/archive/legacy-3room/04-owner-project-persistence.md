# 04: Восстановление и перенос проекта владельца

**Status:** wontfix

**Историческая задача.** Локальный проект хранит Blob подложки в IndexedDB. Экспорт JSON переносит план без подложки, по §13. Актуальные задачи: [T10](../../T10-raster-underlay.md), [T20](../../T20-local-projects.md).

## История до перехода

**Прежний статус:** ready-for-agent

**What to build:** Владелец продолжает редактирование после перезагрузки или импорта JSON в другом браузере.

**Прежняя зависимость:** 03 — Смежные помещения и их площади

## Критерии приёмки

- [ ] Автосохранение и перенос через JSON восстанавливают подложку, калибровку, стены, высоту, подтверждённую геометрию распознавания без повторного инференса, контуры и названия помещений с их ID.
- [ ] Некорректный или неподдерживаемый JSON отклоняется с понятным сообщением и сохраняет текущий черновик.
- [ ] Playwright проверяет восстановление после перезагрузки и перенос проекта в чистый браузерный контекст.
- [ ] Сохранены согласованные ADR и единая модель данных для 2D и 3D. Выполнены проверка TypeScript, сборка и применимые проверки Vitest и Playwright для доступных сценариев.
