# 07: Двери, окна и неподвижные препятствия

**Status:** wontfix

**Историческая задача.** Ручные двери и окна входят в MVP. Отдельный тип неподвижного препятствия снят из целевого объёма. Актуальные задачи: [T12](../../T12-openings.md), [T18](../../T18-object-inspectors.md).

## История до перехода

**Прежний статус:** ready-for-agent

**What to build:** Владелец отмечает проёмы и препятствия, а арендатор видит их на опубликованном плане.

**Прежняя зависимость:** 04 — Восстановление и перенос проекта владельца, 05 — Публикация неизменяемого плана по ссылке

## Критерии приёмки

- [ ] В 2D можно подтвердить предложение распознанного проёма либо вручную добавить дверь или окно на стену, переместить вдоль неё, изменить ширину и высоту проёма и удалить его. Для окна можно задать высоту от пола. Проём за пределами стены отклоняется с подсказкой.
- [ ] В 2D можно добавить прямоугольное неподвижное препятствие, например колонну, задать ширину, глубину и высоту, переместить, повернуть и удалить его.
- [ ] Элементы сохраняются в черновике, восстанавливаются из JSON и включаются в новый снимок при наличии. Оба вида показывают одинаковую геометрию в метрах.
- [ ] Playwright проверяет создание и правку элементов, восстановление проекта и отображение результата по опубликованной ссылке в режиме чтения.
- [ ] Сохранены согласованные ADR и единая модель данных для 2D и 3D. Выполнены проверка TypeScript, сборка и применимые проверки Vitest и Playwright для доступных сценариев.
