# 08: Пробная расстановка оборудования арендатора

**Status:** wontfix

**Историческая задача.** Роль арендатора и режим по ссылке исключены. Расстановка мебели реализуется в локальном конструкторе. Актуальные задачи: [T16](../../T16-furniture.md).

## История до перехода

**Прежний статус:** ready-for-agent

**What to build:** Арендатор открывает ссылку и визуально проверяет, помещается ли оборудование.

**Прежняя зависимость:** 05 — Публикация неизменяемого плана по ссылке

## Критерии приёмки

- [ ] В 2D арендатор добавляет оборудование с уникальным ID и положительными шириной, глубиной и высотой, перемещает, поворачивает и удаляет экземпляры.
- [ ] 3D сразу показывает те же габариты, положения и повороты. План доступен только для чтения, расстановка живёт отдельно от снимка.
- [ ] Playwright проверяет расстановку и просмотр в 3D в контексте арендатора без регистрации.
- [ ] Сохранены согласованные ADR и единая модель данных для 2D и 3D. Выполнены проверка TypeScript, сборка и применимые проверки Vitest и Playwright для доступных сценариев.
