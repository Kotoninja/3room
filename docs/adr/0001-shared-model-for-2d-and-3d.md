# Общая модель для 2D и 3D

2D-редактор и 3D-просмотр используют одну модель проекта. В MVP пользователь редактирует геометрию и размещает мебель в 2D, а 3D строится из актуального состояния модели, чтобы переключение между видами сразу показывало те же правки.

## Последствия

Стены, помещения и экземпляры мебели имеют уникальные идентификаторы. Координаты и размеры хранятся в метрах, высота стен задаётся для проекта. Автосохранение и обмен через JSON работают с моделью проекта.
