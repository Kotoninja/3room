# Опубликованные планы и расстановки арендаторов

Владелец редактирует локальный проект и публикует неизменяемый снимок базовой геометрии с уникальным идентификатором и версией формата. Хранилище публикаций выдаёт снимок по ссылке любому её получателю без регистрации и только для чтения. Снимок содержит данные, необходимые для просмотра и расстановки оборудования. Частные черновики остаются в локальном проекте, а новые правки владельца применяются к его проекту.

Арендатор просматривает план в 2D и 3D и отдельно редактирует экземпляры оборудования с заданной шириной, глубиной и высотой. Расстановка сохраняется в браузере, а экспорт и импорт позволяют перенести её в другой браузер. Она относится к конкретному опубликованному плану. Геометрия плана остаётся доступной арендатору только для чтения.

Публикация отделяет доступ к плану от работы с черновиком: ссылка открывает конкретный снимок, а владелец и арендатор работают со своими локальными данными.

## Состав снимка

Снимок содержит координаты, толщину и высоту стен, границы, размеры и названия помещений, а также двери, окна, колонны и другие неподвижные препятствия, если они есть в модели. Геометрия использует единую систему координат, размеры и координаты выражены в метрах. Исходное изображение PNG/JPEG, мебель из черновика, внутренние заметки и служебные данные хранятся в локальном проекте владельца.

## Доступ к публикации в MVP

Владелец может редактировать и сохранять проект локально без входа. При публикации сервер проверяет общий код доступа для приглашённых тестировщиков. Все тестовые публикации используют один вымышленный профиль владельца. Имена, адреса электронной почты и номера телефонов для выдачи доступа не собираются. Арендатор открывает опубликованный план без регистрации и кода.
