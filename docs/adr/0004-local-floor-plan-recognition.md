# Локальное распознавание чертежей

Распознавание выполняется на устройстве владельца. Базовый кандидат для курсового прототипа — FloorPlanNet Lite INT8 через ONNX Runtime Web WASM. Переход к интеграции зависит от проверки артефакта, условий использования и результата на реальном чертеже. При непригодности модели для чистых прямоугольных планов используется локальный OpenCV.js с тем же интерфейсом распознавания.

RecognitionProvider изолирует модель и движок. GeometryNormalizer и GeometryValidator преобразуют кандидаты в проверенный граф, из которого строятся 2D и 3D. До калибровки кандидаты остаются в пикселях. После калибровки модель проекта хранит метры, а высоту задаёт владелец. Решения о графе стен и публикации снимков действуют и для распознанных проектов.
