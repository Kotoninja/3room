# Новая основа RoomForge

**Статус: принято 2026-11-26.** Заменяет ADR 0001–0004.

[SPEC.md](../../SPEC.md) задаёт чисто клиентский конструктор. План один для SVG и 3D. Стена имеет собственные концы, толщину и высоту, комнаты вычисляются чистой функцией из производного графа. Подложка калибруется отдельно и распознаётся в TypeScript-воркере. Черновик попадает в план после принятия. Проекты и подложки хранятся в IndexedDB. Трактовки и миграционные задачи описаны в [DECISIONS.md](../../DECISIONS.md).
